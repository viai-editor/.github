# ViAI - Vim Advanced Integrated

ViAI (pronounced "vee-eye") is a fork of [Vim](https://github.com/vim/vim),
developed by Hirohito Higashi (h-east), a former Vim maintainer, making full
use of AI assistance.

* The main aim of ViAI is that [lsp.vim](https://github.com/h-east/lsp.vim)
  and [vim9ls](https://github.com/h-east/vim9ls) work well.
* ViAI is the only editor that can show the errors that Vim gives when
  sourcing a Vim9 script as diagnostics, without running the script.
* Your Vim configuration and plugins work in ViAI as they are.

## Getting ViAI

* MS-Windows: download the installer from the
  [releases](https://github.com/viai-editor/viai-win32-installer/releases).
* Unix: build it from the source, see the
  [README](https://github.com/viai-editor/viai#building-and-installing).

## Repositories

* [viai](https://github.com/viai-editor/viai): the source code of ViAI
* [viai-win32-installer](https://github.com/viai-editor/viai-win32-installer):
  the installer of ViAI for MS-Windows
